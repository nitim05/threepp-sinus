# Sinus animasjon

Et enkelt C++-prosjekt som bruker threepp.

- Åtte bokser beveger seg opp og ned i en sinusbevegelse.
- Annenhver boks beveger seg i motsatt fase.
- Trykk på **Space** for å endre fargen på de to gruppene etter tur.

## Kjør programmet

Åpne prosjektet i CLion, la CMake laste inn prosjektet, og kjør programmet.
